# First publication verification

Date: 2026-11-08. Public site: https://jepa.toni.foo/. Source: https://github.com/DebelToni/JEPA-research-landscape.

## Published snapshot

- 1,500 searchable paper records, including 101 source-extracted records.
- 90 papers contain experimental findings: 394 interpretations with 684 selected numerical results.
- 77 provisional empirical appraisals. No record is labelled human-reviewed or semantically verified; extraction completeness remains partial.
- Other candidates, ambiguous identities and source-processing failures remain in the private ledger. A snapshot is not an exhaustive census.

## Technical checks

- 137 Python tests passed on Linux ARM64, Python 3.12.
- Six model-adapter tests passed, including selected-account-only calls and no retry/fallback.
- Four isolated desktop/mobile browser tests passed. Production browser checks cover catalogue navigation, filtering, a direct paper route, findings/evidence, graph, downloads and methodology.
- Public `/cool` → catalogue navigation verified at phone and desktop widths.
- Origin and public health responses pass the read-only uptime check; static startup is enabled, processing is not scheduled.
- Public export removes legacy result-row tables, source quotations, raw abstracts and private processing state. Publisher verifies manifest hashes and rejects backup directories, unmanifested data, hidden files and symlinks.
- Regression checks cover an earlier build-backup leak: backups now live outside the frontend public tree, and `/data.previous/catalog.json` returns 404. No credentials or paper full text were in that legacy backup.
- Parser lifetime tests exercise parent termination, PDF-child termination, race rejection and owned descendant cleanup. Unknown historical chunk-generator provenance is explicitly retained as unknown, separate from current validation.

## Scientific limits

A source audit sampled 20 I-JEPA numerical records across 12 tables. The sampled values matched their source cells; qualification losses and a misleading caption interpretation were identified. The revised output emphasizes findings, selected numbers, caveats and exact source links instead of exhaustive table transcription. This was an AI source audit, not human review or a guarantee for the entire corpus.

Mechanical validation establishes source-location and literal-value correspondence, not the truth of a paper's claims, fair benchmark comparison, code execution, proof correctness or independent reproducibility. Figures and external supplements can remain uninspected. PDF fallback remains low fidelity; richer parsing, broader venue adapters and reviewed identity merges are still open work.
